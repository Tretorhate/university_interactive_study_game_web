# ИнфоКвест

Интерактивная игра по информатике. Тема: **«Біздің айналамыздағы ақпарат» (Информация вокруг нас)**.

Цель обучения **5.2.1.1**: различать виды информации по форме представления (текстовая, графическая,
звуковая, числовая, видео) и понимать, что информация в компьютере хранится в двоичном коде.

## Стек

- React 19 + TypeScript
- TanStack Router (file-based routing, `src/routes/`)
- `@dnd-kit/core` — drag & drop (сортировка карточек)
- `motion` — пружинные анимации и переходы страниц
- `canvas-confetti` — наградная анимация при прохождении
- WebAudio API — синтезированные звуки, без файлов (`src/sfx.ts`)
- ASCII-анимации: поле битов, scramble-эффект, тикер (`src/ascii.tsx`)
- Vite, Bun, Wrangler, Cloudflare Pages

## Запуск

```bash
bun install
bun dev        # http://localhost:5173
bun run build  # tsr generate + tsc + vite build
```

## Публикация на Cloudflare Pages

Сайт размещён на Cloudflare Pages: https://university-interactive-study-game-web.pages.dev/

После входа в Wrangler (`bunx wrangler login`) опубликовать текущую версию можно так:

```bash
bun run deploy:pages
```

Скрипт собирает проект и отправляет `dist/` в Pages-проект `university-interactive-study-game-web` на ветку `main`.

## Структура

| Маршрут            | Содержимое                                                              |
| ------------------ | ----------------------------------------------------------------------- |
| `/`                | Главная: тема, цель обучения, ASCII-поле, карточки игр                  |
| `/theory`          | Теория: 5 форм информации с примерами + блок про двоичный код           |
| `/map`             | Карта игр с прогрессом (звёзды, из localStorage)                        |
| `/levels/types`    | Drag & drop: карточки-примеры → корзины форм (серия/стрик)              |
| `/levels/forms`    | Пары: 12 из 16 случайных пар за запуск, 3 доски по 4                    |
| `/levels/binary`   | Перевод битов ↔ десятичные и шестнадцатеричные числа, веса разрядов     |
| `/results`         | Результаты по цели 5.2.1.1, сброс прогресса                             |

## Игровая логика

- Каждая игра: серия заданий; ошибки считаются, звёзды по итогу (0 ошибок = ★★★, ≤2 = ★★, иначе ★).
- Прогресс хранится в `localStorage` (`infoquest-progress-v1`), лучший результат сохраняется.
- `src/useGame.ts` — общий цикл (ошибки/финиш/рестарт), `src/gameMeta.ts` — реестр игр,
  `src/forms.tsx` — метаданные форм представления, `src/icons.tsx` — SVG-иконки.
- Оформление: светлая тема включена по умолчанию; тёмная включается кнопкой в верхней панели. Выбор сохраняется в `localStorage` (`infoquest-theme-v1`).
